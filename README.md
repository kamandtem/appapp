# کارگردان ژست · Pose Director

دستیار حرفه‌ای هدایت ژست برای عکاسان و فیلمبرداران عروسی. کاملاً آفلاین، فارسی و راست‌به‌چپ.

## چه چیزهایی داخل برنامه است

- **۷۰ ژست کامل** با مراحل اجرا، فرم بدن و دست و پا، جهت سر و نگاه، اشتباهات رایج، تنوع‌ها و تنظیمات دوربین
- **«چی به سوژه بگم؟»** دیالوگ آماده برای هر ژست، با امکان پخش صوتی فارسی
- **بخش لوکیشن‌ها**: جنوب، شمال، کویر، باغ عمارت — همراه با راهنمای نور، بهترین ساعت، استایل لباس، تجهیزات و هشدارهای هر لوکیشن
- **ژست‌های من**: افزودن ژست شخصی با عکس (گالری یا دوربین)، مراحل اجرا، دیالوگ، اشتباهات و تگ برای جستجوی سریع
- **عکس مرجع روی ژست‌های آماده**: برای هر ژست می‌توانید عکس دلخواه خودتان را جایگزین طرح پیش‌فرض کنید
- **حالت عکاسی**: صفحه مخصوص سر صحنه با فونت درشت، تایمر و دکمه «ژست بعدی»
- **منوی کناری** از سمت راست با گوشه‌های گرد، که تمام صفحه را نمی‌پوشاند (با لمس لوگو در هدر باز می‌شود)
- **اسپلش اسکرین و صفحه معرفی** اختصاصی، لوگوی طراحی‌شده و آیکون اندروید
- **دو تم رنگی** (تیره و روشن) با پالت طلایی/رزگلد
- **پشتیبان‌گیری و بازیابی** کل داده‌ها در یک فایل JSON

## اجرا روی کامپیوتر

```bash
npm install
npm run dev
```

سپس مرورگر را روی `http://localhost:3000` باز کنید.

## گرفتن خروجی APK (بدون نصب هیچ چیزی روی سیستم خودتان)

1. یک ریپازیتوری جدید در گیت‌هاب بسازید.
2. محتوای همین پوشه را داخل آن push کنید (روی برنچ `main`).
3. به تب **Actions** بروید. ورک‌فلوی `Build Android APK` خودکار اجرا می‌شود.
4. پس از پایان کار (حدود ۵ تا ۸ دقیقه)، از بخش **Artifacts** فایل `pose-director-apk` را دانلود کنید.
5. داخل آن `pose-director.apk` است؛ روی گوشی نصب کنید.

> این APK از نوع debug است و بدون امضای فروشگاهی روی گوشی نصب می‌شود. برای انتشار در گوگل‌پلی باید نسخه release را با کلید خودتان امضا کنید.

### ساخت محلی APK (اختیاری)

نیاز به Node 20، Java 17 و Android SDK دارد:

```bash
npm install
npm run build
npx cap add android
npx capacitor-assets generate --android
npx cap sync android
cd android && ./gradlew assembleDebug
```

فایل خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`

## ساختار پروژه

```
src/
  data/poses.ts        ۷۰ ژست (۶۰ ژست اصلی + ۱۰ ژست استخراج‌شده از برگه‌های باغ و عمارت)
  data/locations.ts    اطلاعات چهار لوکیشن
  services/storage.ts  ذخیره‌سازی محلی، فیلتر و جستجو، موتور «ژست بعدی»، پشتیبان‌گیری
  services/media.ts    فشرده‌سازی عکس‌های کاربر پیش از ذخیره
  services/speech.ts   پخش صوتی دیالوگ‌ها
  components/          هدر، منوی کناری، کارت ژست، فیلترها، حالت عکاسی، فرم افزودن ژست
  components/PoseVisual.tsx  تصویرسازی آفلاین ژست‌ها (۱۶ طرح × ۴ پالت لوکیشن)
  views/               خانه، کتابخانه، لوکیشن‌ها، نشان‌شده‌ها، ژست‌های من، جزئیات، تنظیمات، معرفی
resources/             آیکون و اسپلش اصلی برای تولید خودکار خروجی اندروید
```

## نکته درباره عکس ژست‌ها

نسخه اولیه، عکس‌های تصادفی و نامرتبط از اینترنت می‌گرفت که هم به ژست ربطی نداشتند و هم در حالت آفلاین اصلاً نمایش داده نمی‌شدند. الان برای هر ژست یک **طرح راهنمای فرم بدن** به صورت SVG و کاملاً آفلاین تولید می‌شود، و هر جا خواستید می‌توانید عکس مرجع واقعی خودتان را روی ژست بگذارید.

### جستجوی فارسی هوشمند
جستجو نرمال‌سازی فارسی دارد، «ی/ي»، «ک/ك»، نیم‌فاصله و اعراب را یکسان می‌کند، مترادف‌های رایج مثل «قدم زدن/راه رفتن»، «آغوش/بغل» و «عمارت/باغ» را می‌شناسد و غلط‌های تایپی کوتاه را با فاصله ویرایشی پیدا می‌کند.
