# UX redesign

- Rebuilt home around the on-set decision flow.
- Added a central quick-start action to bottom navigation.
- Promoted shot lists to a first-class navigation destination.
- Reworked filters with progressive disclosure and removable active chips.
- Simplified pose-card actions and hid destructive actions for built-in poses.
- Replaced the visual system with a cream, olive, and orange light-first palette.
- Set light mode as the default for new users.
- Added a Persian UX audit in `UX-AUDIT-FA.md`.
